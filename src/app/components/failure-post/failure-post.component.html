Error al crear la publicación.

Ocurrió un error al crear la publicación. Recordá que solo se permite una publicación por tipo de trabajo (por ejemplo, una como pintor, otra como plomero, etc.). Además, no es posible crear publicaciones desde pestañas en modo incógnito, Si no tenés otra publicación activa para este oficio, por favor cerrá el modo incógnito y volvé a intentarlo.
